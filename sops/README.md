# SOPs

Standard operating procedures — the “how” of daily work.

## Suggested first SOPs to write

- `vehicle-intake.md` — from arrival to opened job
- `estimate-and-approval.md` — quoting, supplements, customer approval
- `repair-and-qa.md` — shop floor flow and quality checks
- `delivery-and-closeout.md` — handoff, billing, follow-up

Each SOP should include: purpose, who owns it, tools/systems used, steps, and what “done” looks like.
