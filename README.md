# Flow Autobody — Company Brain

This repo is the shared source of truth for how Flow Autobody works: who we are, how we operate, and how we decide.

## Start here

1. [About the business](about.md)
2. Browse the folders below for the topic you need
3. Prefer short, dated notes over long unowned docs

## Folder map

| Folder | What belongs here |
| --- | --- |
| `sops/` | Step-by-step operating procedures (how we do the work) |
| `policies/` | Rules and non-negotiables (what we always / never do) |
| `people/` | Roles, owners, and who to ask |
| `services/` | What we sell and how we scope it |
| `customers/` | Customer journey, communication norms, escalation |
| `playbooks/` | Recurring situations (intake, estimate, insurance, delivery) |
| `templates/` | Reusable checklists, email/SMS drafts, forms |

## How to add knowledge

- One topic per file; use clear names (`sops/vehicle-intake.md`)
- Put the owner and last-reviewed date at the top of every doc
- Link related docs instead of duplicating them
- If it’s outdated, fix it or mark it `status: outdated` at the top

## Owners

- Repo owner: update `people/owners.md`
